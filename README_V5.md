# NexusMart V5 — Qatar Commercial Launch Edition

V5 builds on the V4.5 Qatar Expansion package and adds commercial-launch hardening:

- production environment configuration
- explicit client/server secret separation
- error boundary
- three-locale copy foundation (English, বাংলা, العربية)
- subscription plan/trial data model
- production CI/CD workflow for Supabase migrations and Edge Functions
- launch acceptance checklist
- offline shell remains presentation-only; financial transactions are not silently queued as successful sales

## Important
This package is a production-oriented codebase, not a claim of legal/tax certification. Qatar invoice/tax configuration must be validated for each merchant and current requirements.
